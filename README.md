# 极光免费 VPN · Android 开发版

面向安卓手机的免费公共节点客户端：自动获取公开线路、检测可达性、选择线路并连接。不需要注册账号、填写 API Key、购买套餐或自行部署服务端。

**状态：0.6 开发测试版，不能视为已验证的商用品。** 本仓库提供应用界面和节点发现代码；通过固定版本的 OpenVPN for Android 源码构建为同一个 APK，无须另装连接引擎。APK 编译结果见 Actions；真机连接验收仍需进行。

0.3 限制原生内核重试次数、TCP 建连和 TLS 握手窗口；使用不受状态回调重置的单调时钟截止时间；断开任务独立于下载任务；停止超过 8 秒未确认则结束自动连接，避免无限等待或重叠启动。授权在启动计时前完成，支持查看和复制最近连接诊断。自动换线需要内核停止确认。公开 TCP 节点在某些网络可能全部不可达，界面修复不能保证公共节点可用。

0.2 修复“搜索不到节点”：允许借助手机已有的其他 VPN 获取列表；保存最近成功获取的公开列表；每次构建把真实公开源生成的带日期快照装入 APK，七天内可作为离线候选。刷新时先展示本地列表，再尝试在线更新和端口检测。页面持续显示数据来源、时间、候选数及失败原因。候选不代表能连接。0.6 起，端口检测全部失败时明确停止，不再启动这些候选的隧道。

## 功能

- 深蓝渐变首页、大号连接按钮、实时内核连接状态和流量计数。
- 内置 VPN Gate 公共 CSV 地址，HTTPS 获取，不需要用户配置 API。
- 最多选取 40 个源站标称带宽较高的 TCP 节点，4 路并发进行有超时的 TCP 可达性检测。
- 按本机 TCP 连接耗时排序；自动优选最多尝试最多 6 条不同候选；每条连接上限 25 秒，停止等待上限 8 秒。用户授权等待不计时。
- 国家/IP 搜索、收藏标记、来源/检测时间/公共节点风险说明。
- 原生 OpenVPN 全局隧道、Android 系统授权、内核前台通知与断开连接。
- 连接后手动执行约 1 MiB 的 HTTPS 下载测试，检查当前网络确实为 VPN 网络；显示该次下载平均 Mbps。
- 无广告、支付、账号系统或自建后台。不会伪造国家、延迟、剩余流量或“已连接”状态。

## 安装与使用

1. 打开本仓库 **Actions → Android APK**，进入对应开发分支最新成功的构建。
2. 下载 `aurora-free-vpn-debug`，解压并安装其中的通用 APK，兼容 ARM、ARM64、x86、x86_64。
3. 首次打开，阅读并接受免费节点说明，应用自动获取与检测线路。
4. 点击“自动优选连接”，确认 Android VPN 授权；也可以在线路页选定节点后点击首页圆形按钮。
5. 先检测当前底层 Wi-Fi/移动网络到节点端口的连通性，只有通过的线路进入连接队列。内核建立隧道后，还需通过 VPN 网络内连续 HTTPS 验证，才显示“已验证联网”。点击“检测当前隧道下载速度”可测本次实际下载速度。

调试 APK 仅供测试。不同构建机器的调试签名可能不同，跨构建更新可能需要先卸载；正式发布前应配置长期发布签名。首次下载安装仍需 Android 的安装授权和 VPN 授权，应用不能跳过系统提示。

## 免费与速度的边界

VPN Gate 由志愿者提供线路，免费且无需注册，但节点随时可能离线或拥堵。应用仅使用公开自愿提供的 VPN 线路，不收集付费订阅密钥。

| 显示项 | 含义 |
|---|---|
| 标称 Mbps | VPN Gate 提供的服务器测速数据，**不是你的实测带宽** |
| TCP ms | 此手机到节点端口的连接耗时，**不等于隧道可用** |
| 已验证联网 | Android VPN 网络内连续 HTTPS 请求成功，**不保证所有网站可达或持续稳定** |
| 本次下载 Mbps | 当前 VPN 网络内向 Cloudflare 下载至多 1 MiB 的平均速度，包含建立 HTTPS 连接耗时 |

线路页持续标记“公共节点 / 日志风险”。VPN Gate 及节点运营者可能保留日志，不承诺匿名或隐私。HTTPS 和 VPN 证书校验保持启用，不会为连通而忽略证书错误。原始公开配置经白名单检查，不执行脚本、插件或外部文件引用。只接受带内联 CA 的 TCP/tun 配置。

公共源：<https://www.vpngate.net/api/iphone/>。源站被阻断、网络断开或源格式变化时，应用会显示错误并尝试最近七天内的缓存或 APK 快照；过期或损坏的快照不会作为新鲜数据使用。APK 快照是构建时从真实公开源取得的配置，不是编造或固定写死的服务器。可借助现有 VPN 获取最新列表；0.6 的端口检测固定使用底层非 VPN 网络，不把其他 VPN 的可达性算作直连结果。

## 开发与可复现构建

需要 Git、Python 3、JDK 17、Android SDK 36、NDK `29.0.14206865`、CMake、SWIG。

```bash
git clone --recursive https://github.com/54854434/my-first-codex1.git
cd my-first-codex1
git checkout codex/aurora-vpn-android
git submodule update --init --recursive
bash scripts/test.sh
java -cp .checks com.aurora.vpn.GateSeedBuilder overlay/assets/gate-seed.csv
python3 scripts/prepare.py
bash upstream/gradlew -p upstream :main:assembleUiOvpn2Debug
```

内核固定到 OpenVPN for Android v0.7.64，提交 `73ce3c99dde39207990d66c21be8201228cd1f09`，及其递归子模块。`scripts/prepare.py` 检查固定提交后，将 `overlay/` 复制到内核的 UI 源集，修改应用 ID 和启动入口；保留内核 VPN 服务及状态监听机制。包名为 `com.aurora.freevpn`，最低 Android 8.0。升级内核时应明确修改固定提交并重新验证，不自动跟随上游主分支。

`config/lint-baseline.xml` 记录固定内核中原有的 36 项 `ImpliedQuantity` 多语言数量词资源问题，路径均为未修改的上游 `src/ui/res/values-*/plurals.xml`。本项目新增源码不在基线内；没有关闭 lint 的错误阻断。测试会核对基线的数量、检查类型和文件范围。APK 生成、上传与 lint 分步执行，检查报告保留在 Actions。

## 已知限制与验收

- 当前自动发现使用 VPN Gate（含同源备用镜像）和 VPNBook；只纳入可预检的 OpenVPN TCP 线路，不含 WireGuard、VLESS、Trojan 或 UDP。
- 收藏只做标记；最近成功获取的原始公开列表保存于应用私有目录，七天内有效，更新成功后替换。
- 自动换线仅在当前 Activity 存活时运行；关闭界面后已建立的隧道由内核后台服务维持。本版没有完整的后台自动换线调度。
- 公共源中的城市信息不完整，因此只展示真实国家信息，不编造城市或地图位置。
- 隧道断开后 Android 可能恢复直连。需要断线阻断时，在系统 VPN 设置中开启“始终开启 VPN”及“阻止不使用 VPN 的连接”，并在设备上验证。
- 测速地址为 `https://speed.cloudflare.com/__down?bytes=1048576`，第三方服务可失效或限流。
- 正式商用前仍需 Android 8/12/14/16 真机连接、DNS/IPv6 路由与泄漏测试、Wi-Fi/移动网络切换、后台存活、撤销授权、证书失败、节点全失效等验收。没有完成这些验证前，不宣称达到商业 VPN 的可靠性。

### 连接失败诊断（0.3）

首页“查看连接诊断”可复制最近 60 条状态，内容仅含公共节点 IP、状态码及尝试时间，不含密钥或证书。`CONNECTRETRY` 表示尚未建立隧道。原生 TCP 超时 8 秒、TLS 窗口 15 秒、重试上限 1；UI 每条独立截止时间 25 秒，不随原生重试重新计时。断开控制使用独立队列；停止成功需 RPC 返回并得到停止状态（或内核确认没有进程）。超过 8 秒未确认则停止自动换线并要求系统设置断开，避免重叠连接。

CI 额外对六个公开节点执行限时 OpenVPN 握手测试，使用 dev-null、不创建 TUN、不改路由、不执行配置脚本；只输出经过筛选的状态到 `public-handshake-report` 构建附件。报告只反映构建网络，不能证明用户手机网络可达，也不保证后续节点继续在线。

### Android 实际联网验收（0.4）

构建后在 Android API 35 x86_64 模拟器安装实际 APK 和单独测试 APK，走应用自身刷新和自动连接流程；必须同时满足原生 CONNECTED、Android VPN Network、该 Network 内 HTTPS 成功且出口 IP 与连接前不同。测试失败会阻止上传可下载 APK，保留脱敏原生错误、诊断 JSON 和截图。模拟器结果不能代表用户手机网络。应用本身在 CONNECTED 后还需通过 VPN Network 完成 HTTPS 才显示“已验证联网”；失败继续有限换线。


### 多源发现与本机证据（0.5）

新增 VPNBook 官方公开 OpenVPN 下载，自动读取公开共享凭据，不要求用户填 API 或注册账号；每次刷新重新读取，支持其密码轮换。配置必须通过既有的公网地址、TCP/tun、内嵌 CA 和指令白名单检查。VPN Gate 主站失败后可使用 GeorgeXie2333 的公开 GitHub/CDN 镜像；镜像仍属于同一个 VPN Gate 节点池，不算独立运营商。IPSpeed 在构建环境返回 403，未加入自动获取。Proton 等需个人账户的方案不使用共享个人账号。

两类来源并行获取、按来源均衡抽样，再做端口探测；来源名称随缓存保留。源站带宽为 0 表示未提供，不代表测速结果。只有本机 VPN 内 HTTPS 成功才记录本机优选证据；Wi-Fi、移动网络、其他网络分别记录，未读取 SSID。证据优先期为六小时，历史一天后过期。失败冷却从一分钟递增，上限十五分钟；用户主动取消、无网和暂停不记作节点故障。仍允许手动选择冷却中的线路。

验证任务支持取消和过期结果丢弃，最多三个并行验证任务且没有排队积压。新的安卓验收包含断开、重建 Activity、验证成功节点优先，以及第一条候选再次完成 VPN HTTPS。此测试仍仅代表 CI 模拟器网络，不能证明用户手机或运营商网络可达，也不保证高速。

0.5 验收进一步要求客户端连续两次独立 HTTPS 成功，并关闭验证请求的连接复用。首次 0.5 运行发现一条线路单次验证成功后立即复查超时，不能将它视为稳定可用；失败的构建未发布 APK。

运行验收进一步修正：未验证的候选按提供方轮流进入尝试队列，避免六条都被一个低延迟来源占满；使用服务器推送的 DNS；NONETWORK 事件在原有期限内等待恢复，避免网络切换瞬态立即取消全部候选。

### 当前底层网络检测（0.6）

获取来源列表仍可借助已有 VPN；TCP 可达性和建连延迟改为显式绑定手机的非 VPN 底层 Network。当前默认网络为 Wi-Fi/移动网络时优先使用它；默认网络为 VPN 时只从系统可见的非 VPN Internet 网络中选择，找不到就报错，不回退到 VPN 默认路径。列表标注直连网络和网络编号，网络已变时旧延迟标为过期。

自动和手动连接前重新探测；只有当前底层网络 TCP 通过的候选才能进入连接队列。每次启动内核前还会复检目标端口。测量期间网络变化则丢弃结果。所有端口失败时明确显示未启动隧道，不继续把已知失败的候选当作可用线路。系统的 VPN 锁定/禁止直连策略可能阻止检测，此时应关闭其他 VPN 后重测。TCP 延迟不是隧道内时延，也不是带宽或 OpenVPN 握手成功证明。

验收增加：在 VPN 正在联网时选择非 VPN 底层网络，使用绑定该网络的 SocketFactory 重新探测候选，确认检测网络与 VPN 网络不同。保留实际 VPN HTTPS、改变出口 IP、断开、Activity 重建和优先重连验收。模拟器的可达性不能证明用户手机运营商网络可达。
