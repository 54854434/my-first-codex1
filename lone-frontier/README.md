# 孤军：重生战役 v2.0

一款横屏安卓单机游戏，将幸存者式走位、自动攻击、三选一成长，与军团编组、据点攻防和永久重生结合。完整重做 v1 固定防线玩法。

## 玩法

- 摇杆操控指挥官自由移动，主角与军队自动攻击。点击地面设置自动路线，操作摇杆取消自动路线。支持同时移动与使用技能。
- 经验晶体需要靠近拾取；局内升级三选一，可形成无人机、火炮、贯穿、手雷、护盾等构筑。
- 招募步兵、机枪、军医、狙击、迫击炮和坦克，不同兵种占用不同编制。
- 军队可跟随、驻守，或通过战术地图独立远征，主角可以与部队分别行动。
- 每战区有 10 处据点。消灭守军、摧毁建筑，并由友军在附近驻留 4 秒即可占领。占领后持续产出补给，兵营与工厂解锁兵种。
- 敌军会反攻并夺回据点。战俘营可救出步兵，医疗营地可恢复全军生命。
- 占领 3 处据点解除总部护盾，夺取总部后可保留军队与局内成长，推进更强的新战区，无固定最终战区。
- 敌军随时间与战区持续增强，开局仅 60 补给，优先购买一名步兵仍需走位和支援；站桩并不能安全度过开局。
- 阵亡或主动撤离按歼敌、占领、时间和战区结算永久研究点。有效结算还叠加永久 2% 传承伤害与生命。新生命重置战场与局内成长，研究和传承永久保留。
- 每 5 秒及切到后台保存；后台暂停战斗，已占据点提供 25% 效率、最多 4 小时的离线收入。
- 暂停菜单支持复制和恢复完整存档。v1 勋章可迁移为研究点，并在 v2 存档内保留原始旧存档。

支持 Android 8.0+，建议使用更新后的 Android System WebView。无广告、无内购、无运行时网络请求。包名维持 `com.lonefrontier.game`，使用此前交付的相同签名，可覆盖安装升级。

## 构建

需要 JDK 17、Node.js 18+、Android SDK Platform 35、Build Tools 35.0.0、zip。无需 Gradle 或外部游戏引擎。

```bash
sdkmanager 'platforms;android-35' 'build-tools;35.0.0'
export ANDROID_HOME=/your/android-sdk
bash scripts/build.sh
```

输出：`dist/LoneFrontier-Rebirth-v2.0.0.apk`。

使用 `.signing/frontier.jks`，别名 `frontier`，库与密钥密码为 `android`。之前交付的签名备份与 v2 本地交付包使用同一密钥。GitHub 不存放密钥；云端每次构建会生成自己的测试签名。设置 `FRONTIER_KEYSTORE` 可指定现有签名文件。

源码位于仓库 `lone-frontier/`，Actions 位于根 `.github/workflows/lone-frontier.yml`。工作流会独立编译，并在 Android 11 模拟器测试安装、横屏、招兵、移动、战术地图、远征命令、存档、后台恢复及进程重启恢复。

## 验证与代码

```bash
node --test tests/engine.test.cjs
```

18 项核心测试覆盖开局压力、军队成本与解锁、移动、指令、技能、占领与反攻、总部护盾、升级选择、连续碰撞、永久结算、无限增压、完整存档和旧版迁移。

- `engine.js`：纯逻辑战役模拟。
- `renderer.js`：原创程序化军事场景、部队、建筑、地图、战斗反馈。
- `game.js`：界面、存档、生命周期与交互。
- `input.js`：支持多指操作的虚拟摇杆和键盘输入。
- `spatial-hash.js` / `steering.js`：从 GitHub MIT 项目复用并适配的基础组件。

开源来源与修改说明见 [THIRD_PARTY.md](THIRD_PARTY.md)。许可证随源码和 APK 一起分发。
